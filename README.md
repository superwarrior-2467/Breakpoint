# Breakpoint

> A lightweight, high-performance break reminder built with **Silk.NET**.

Breakpoint is an open-source application designed to help users maintain healthier computer habits by enforcing break schedules such as the **20/20/20 rule**, **50/10**, and other customizable work/rest intervals.

Unlike many reminder applications that rely on heavyweight UI frameworks, Breakpoint is built directly on **Silk.NET** with performance as a first-class priority. The goal is to consume as little CPU time and memory as possible while running silently in the background.

---

## 🚧 Project Status

> **This project is currently in active development.**

Breakpoint is **not yet production-ready**.

At this stage you may experience:

* Application crashes.
* Empty or incomplete windows.
* Features that are partially implemented.
* Missing functionality.
* Unexpected behavior.

These issues are expected while the project is under active development.

## ✨ Features (Planned)

* Enforce the **20/20/20** eye care rule.
* Support for **50/10**, **Pomodoro**, and custom schedules.
* Extremely low memory usage.
* Minimal CPU overhead.
* Native rendering through Silk.NET.
* Runs quietly in the background.
* Modern and lightweight user interface.
* Cross-platform architecture (planned).
* Configurable notifications and reminders.
* Open source and community-driven.

---

## 🎯 Goals

Breakpoint has three primary goals:

* Help users reduce eye strain and fatigue.
* Stay as lightweight as possible.
* Provide a clean and extensible codebase for contributors.

Performance is considered a core feature of this project.

## 📦 Building

Clone the repository:

```bash
git clone https://github.com/<username>/Breakpoint.git
```

Enter the project:

```bash
cd Breakpoint
```

Build using the .NET CLI:

```bash
dotnet build
```

Run:

```bash
dotnet run
```

## ❤️ Why this project?

Many existing break reminder applications consume more resources than necessary for such a simple task.

Breakpoint aims to demonstrate that a desktop application can remain responsive, modern, and efficient while using only the resources it actually needs.

The project also serves as an exploration of high-performance desktop application development using Silk.NET and modern .NET.
