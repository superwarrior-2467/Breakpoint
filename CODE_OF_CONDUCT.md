# Code of Conduct

## Our Commitment

Breakpoint is an open-source project dedicated to promoting healthier computer
usage habits by encouraging regular breaks through transparent, user-controlled
reminders.

We are committed to maintaining a welcoming, respectful, and professional
community where contributors collaborate in good faith and with respect for
both users and fellow developers.

---

# Expected Behavior

All contributors are expected to:

* Be respectful and constructive.
* Welcome new contributors.
* Accept feedback professionally.
* Prioritize code quality and maintainability.
* Report security concerns responsibly.
* Respect differing opinions and technical approaches.

---

# Unacceptable Behavior

The following behaviors are not tolerated:

* Harassment or discrimination of any kind.
* Personal attacks or abusive language.
* Intentionally disruptive behavior.
* Knowingly introducing malicious code.
* Submitting code intended to compromise user privacy or security.
* Using the project to facilitate illegal activities.

---

# Project Ethics

Breakpoint interacts with low-level operating system APIs in order to temporarily
restrict user interaction and encourage scheduled breaks.

These capabilities exist **solely** to help users voluntarily maintain healthier
work habits.

The application is designed around the following principles:

* The user is always aware that Breakpoint is running.
* User interaction is never hidden or deceptive.
* Break reminders are intended for the benefit of the user.
* Transparency takes priority over intrusive behavior.
* The software should never attempt to conceal its operation.

Breakpoint is **not** designed to function as malware, ransomware, spyware,
screen lockers, or any other form of malicious software.

---

# Responsible Use

By contributing to this project, you agree that contributions should not:

* Attempt to bypass user awareness.
* Introduce persistence mechanisms intended for malicious purposes.
* Hide or disguise application behavior.
* Circumvent operating system security features.
* Facilitate unauthorized access to systems.
* Assist in the development of malware or malicious tooling.

Any contribution whose primary purpose is offensive, deceptive, or malicious
may be rejected without further discussion.

---

# Security

If you discover a security vulnerability, please report it responsibly rather
than publicly disclosing exploit details before maintainers have had an
opportunity to address the issue.

---

# Enforcement

Project maintainers reserve the right to reject contributions, close issues, or
remove participants whose behavior conflicts with this Code of Conduct or the
ethical goals of the project.

Our objective is to ensure that Breakpoint remains a trustworthy, transparent,
and community-driven project dedicated to improving users' well-being.
